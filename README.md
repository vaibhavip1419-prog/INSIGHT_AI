# INSIGHT_AI – AI-Powered Customer Feedback & Business Analytics System

## 📌 Project Overview

INSIGHT_AI is an AI-powered customer feedback and business analytics system that uses Machine Learning and Natural Language Processing (NLP) to analyze customer reviews and generate meaningful business insights.

The system performs customer sentiment analysis and helps identify areas that may require business improvement.

## 🌐 Live Streamlit Application

https://vaibhavip1419-prog-insight-ai-app-gevn21.streamlit.app/

## 🚀 Key Features

- Customer Review Analysis
- NLP Text Preprocessing
- TF-IDF Feature Extraction
- Sentiment Classification
- Product/Department Analysis
- Business Insights
- Interactive Streamlit Dashboard
- Machine Learning Prediction
