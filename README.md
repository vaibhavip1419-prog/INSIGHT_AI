# INSIGHT_AI

## AI-Powered Customer Feedback & Business Analytics System

### 🚀 Live Streamlit Application

[Open INSIGHT_AI Application](https://vaibhavip1419-prog-insight-ai-app-fuuvan.streamlit.app/)

### 📊 Project Description

INSIGHT_AI is an AI-powered customer feedback and business analytics system that uses Natural Language Processing and Machine Learning to analyze customer reviews and predict sentiment.

### 🛠 Technologies Used

- Python
- Streamlit
- Natural Language Processing (NLP)
- TF-IDF
- Logistic Regression
- Random Forest
- Pandas
- Scikit-learn
- Power BI

### 📂 Dataset

Women’s E-Commerce Clothing Reviews

Source: [Kaggle Dataset](https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews)
